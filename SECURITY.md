# Security policy

## Reporting a vulnerability

Please report security problems privately, never in a public issue or pull request:

- **GitHub:** use **Report a vulnerability** in this repository's **Security** tab.
- **Email:** write to contact@sharadox.com.

Describe the problem, how to reproduce it and what it affects. You'll get an answer within a few working days, and we'll keep you informed until it is fixed. Once a fix is released, we're happy to credit you, if you'd like.

## Supported versions

Only the latest release receives security fixes.
